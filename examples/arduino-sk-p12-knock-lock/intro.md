## What you see
Knock Lock: knock the piezo 3 times to unlock a servo. A button re-locks it. LEDs show state.

## Try this
1. Run the program and interact with the inputs.
2. Change parameters and observe the effect.

## What is going on
This Arduino Starter Kit project demonstrates a practical interaction pattern.
