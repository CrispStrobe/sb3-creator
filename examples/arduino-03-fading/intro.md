## What you see
An LED on pin D9 fades smoothly from off to full brightness and back, repeating forever. No potentiometer needed — the brightness is generated by the program.

## Try this
1. Run the program and watch the LED breathe.
2. Change the step from 5 to 1 for a slower, smoother fade.
3. Change the step to 50 for a visible staircase effect.

## What is going on
The program sweeps a variable from 0 to 255 in steps, setting the PWM duty cycle at each step. At duty 0 the LED is off; at 255 it is fully on. The fade-down reverses the sweep. PWM switches the LED on and off thousands of times per second — your eye averages it into perceived brightness.
