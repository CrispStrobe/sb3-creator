# Descending sum / Absteigende Summe

**EN.** Add the integers from 7 down through 1. Load the program, enter `010 PC RUN`, and wait for `P  025`. Press **ACC** for `A00.028`. Cell 030 contains `00.000` and cell 031 contains `00.028`. A comparison to zero ends the loop before another subtraction. The run executes 72 teaching instructions, with no programmed delay. Base memory suffices. The program occupies 010–024 and 030–033 and needs no terminal connections.

**DE.** Addiere die ganzen Zahlen von 7 abwärts bis 1. Programm laden, `010 PC RUN` eingeben und auf `P  025` warten. **ACC** zeigt `A00.028`. In Zelle 030 steht `00.000`, in Zelle 031 steht `00.028`. Der Vergleich mit null beendet die Schleife vor einer weiteren Subtraktion. Der Ablauf umfasst 72 Lehrbefehle ohne programmierte Wartezeit. Der Grundspeicher genügt. Belegt sind 010–024 und 030–033. Externe Anschlüsse sind nicht erforderlich.
