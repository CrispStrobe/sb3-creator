# NXT-Faceplate

Der NXT-Mindstorms-Baustein hat ein monochromes 100×64-LCD und drei
Tasten. Dieses Faceplate stellt das Display und die Tasten im
Controller-Panel dar.

## Probiere das
1. Klicke **Im Simulator ausfuehren** — das Display zeigt "NXT 2.0".
2. Druecke **▶** zum Blaettern: Sensoransicht, Motorstatus, Systeminfo.
3. Druecke **◀** zum Zurueckgehen.
4. Druecke **●** zur Auswahl des aktuellen Modus.

## Was passiert hier
Das **mono_lcd**-Widget (100×64) stellt die Variable `nxt_display` dar.
Das Programm wechselt mit den Links/Rechts-Tasten zwischen Infoseiten.
Dies passt zur NXT-Erweiterung — Tastsensor, Lichtsensor,
Motorpositions-Tracking.
