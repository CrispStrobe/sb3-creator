# A number makes a round trip

Store one input word, output that same cell, then halt.

Load the program and its input strip. Before each instruction, predict the next PC and which memory cell or output changes. INP writes memory; OUT reads memory. The accumulator is not needed for this program. Clear or reload the run before trying another number.

This original exercise uses a decimal educational machine. It is not a generic Scratch, Python, JavaScript or C compilation target.
