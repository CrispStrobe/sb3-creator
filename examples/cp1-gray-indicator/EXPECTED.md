# Gray indicator / Gray-Anzeige

**EN.** Observe P2 terminals 1–3 with a logic analyzer or three appropriately driven indicators. Enter `008 PC RUN`. P2 emits `F8 F9 FB FA FE FF FD FC` in hex, starting with the first write after RUN. Each adjacent pair differs at exactly one terminal. Terminals 4–8 are held high throughout the sequence. Each level lasts approximately 84 ms, with an acceptance range of 70–105 ms between successive changes. Expect `P  020` within one second of the first write and P2 to remain `0xFC`. The run executes 72 teaching instructions, including eight delays of 75 units each. Base memory suffices. The program occupies 008–019, 030–032, and 044–051.

**DE.** P2-Anschlüsse 1–3 mit einem Logikanalysator oder drei geeigneten Anzeigen beobachten. `008 PC RUN` eingeben. Ab dem ersten Schreibvorgang nach RUN erscheinen an P2 die Hexwerte `F8 F9 FB FA FE FF FD FC`. Zwischen zwei aufeinanderfolgenden Werten wechselt jeweils genau ein Anschluss den Pegel. Die Anschlüsse 4–8 bleiben während der Folge High. Jeder Zustand dauert ungefähr 84 ms. Zwischen zwei Wechseln sind 70–105 ms zulässig. Innerhalb einer Sekunde nach dem ersten Schreibvorgang erscheint `P  020`, und P2 bleibt auf `0xFC`. Der Ablauf umfasst 72 Lehrbefehle, darunter acht Wartezeiten zu je 75 Einheiten. Der Grundspeicher genügt. Belegt sind 008–019, 030–032 und 044–051.
