## What you see
Fades LEDs on pins D2–D4 using PWM. Written for the Arduino Mega (more PWM pins than the Uno).

## Try this
1. Run the program and observe the behavior.
2. Change a parameter and see how the output changes.

## What is going on
This sketch demonstrates an Arduino analog I/O pattern. See the .bw file for details.

## Go further
- Experiment with different values and combinations.
