## What you see
A light sensor (LDR) on A0 controls the pitch of a buzzer on D9 — more light means higher pitch.

## Try this
1. Run the program and observe the behavior.
2. Change a parameter and see how the output changes.

## What is going on
This sketch demonstrates an Arduino programming pattern. See the .bw file for details.
