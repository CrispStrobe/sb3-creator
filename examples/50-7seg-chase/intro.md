## What you see
A seven-segment display wired the honest way: seven pins, seven resistors, one segment each — every segment is just an LED between its pin and the common cathode. The chase walks a→f around the ring, then blinks the middle bar. This example works on all supported microcontrollers — pick a different device in the toolbar to see the adapted circuit.

## Try this
1. Run it and watch which segment lights for which pin — the display face mirrors the real currents.
2. Change the wait times; make the chase run backwards.
3. Challenge: light the pattern for the digit 3 (segments a, b, c, d, g).
