# Bis einschließlich null herunterzählen

TAC springt nur bei einem negativen Akkumulatorwert.

Die Eingabe 003 ergibt 003, 002, 001, 000. Die nächste Subtraktion speichert -001; danach erreicht TAC den HRS-Befehl, ohne -001 auszugeben. Probiere 000 und -001 in getrennten neuen Läufen. Erkläre, warum null ausgegeben wird, ein negativer Startwert aber nicht.

Diese eigenständig verfasste Übung nutzt eine dezimale Lernmaschine. Sie ist kein allgemeines Übersetzungsziel für Scratch, Python, JavaScript oder C.
