## What you see
Smooths analog readings using a running average of 10 samples — reduces noise from jittery sensors.

## Try this
1. Run the program and observe the behavior.
2. Change a parameter and see how the output changes.

## What is going on
This sketch demonstrates an Arduino analog I/O pattern. See the .bw file for details.
