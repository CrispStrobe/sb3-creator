# Ein nachvollziehbares Nachtlicht

Gib unterhalb einer Schwelle 001 aus, sonst 000; der moderne Adapter kann eine LED ansteuern.

Eingaben unter 500 ergeben 001; Eingaben ab 500 ergeben 000. Der mitgelieferte Streifen ergibt 001, 000, 000, 001; danach wartet die Maschine auf eine weitere Eingabe. Numerische Ein- und Ausgabe sind die CARDIAC-Schnittstelle. Ein Brickwright-Schaltungsadapter ist eine moderne Erweiterung: Abtastung, Ausgangslatch, Spannungsumrechnung und LED-Schaltung müssen getrennt geprüft werden. Die Übung behauptet keine historischen GPIO-Pins oder einen historischen elektrischen Takt.

Diese eigenständig verfasste Übung nutzt eine dezimale Lernmaschine. Sie ist kein allgemeines Übersetzungsziel für Scratch, Python, JavaScript oder C.
